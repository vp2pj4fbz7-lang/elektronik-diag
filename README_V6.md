Elektronik Diag V6 – Akademia Diagnostyki

Nowości V6:
- osobna zakładka Akademia Diagnostyki,
- 20 lekcji szkoleniowych z diagnostyki elektroniki,
- quiz na końcu każdej lekcji,
- zapisywanie ukończonych lekcji w localStorage,
- pasek postępu,
- interaktywny Trener usterek z przypadkami warsztatowymi,
- zachowane moduły V5: Diagnostyka PRO, Internet, Atlas podzespołów i Datasheet,
- cache Service Workera zmieniony na elektronik-diag-v6-0.

Instalacja GitHub Pages:
1. Wgraj index.html, sw.js i manifest.webmanifest.
2. Zachowaj/wgraj swoje istniejące icon-192.png i icon-512.png, jeśli były używane w repozytorium.
3. Po aktualizacji odśwież stronę. Jeśli urządzenie długo pokazuje starą wersję, zamknij PWA/kartę i otwórz ponownie.

Uwaga bezpieczeństwa:
Materiały są pomocą szkoleniową. Pomiary części sieciowej, HV i akumulatorów Li-ion wymagają odpowiednich kwalifikacji, izolacji i sprzętu pomiarowego.
